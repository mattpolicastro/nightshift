Implement these 13 tasks in numbered order in one change/PR. Do not deploy intermediate commits. For this retirement, the approximately 300-line ceiling applies to lines added or modified, including tests, fixtures, documentation and import cleanup. Deleting whole files or contiguous retired code/test blocks counts as one concern regardless of removed line count; do not split those deletions into separate cycles. Replacing a block still counts all replacement lines toward the budget. Ranges below estimate added or modified lines only. Boundaries are fixed now because implementing agents cannot edit openspec/**. Retire tests only for the exact removed contract named here and in `design.md`; shared behavior remains protected.

Every task runs `uv run pytest` and the applicable type check and leaves the suite green. Retained-contract migrations precede deletions and pass against intermediate and final code. Replace worker-only progress assertions with actual specloop progress, never skipped tests, permissive monkeypatches or no-op stubs. Resolved/deleted diagnostics may remain because the checker rejects only new diagnostics. For any new rich-text structural check apply `design.md`'s literal raw-line rule and block on ambiguity; do not parse fences, HTML or indentation semantically. Live config, installed plists and external scripts are exclusively the PR human checklist.
